## 2. Research Findings

### 设计稿分析（image-4.png 右侧预览区）
- **A4 纸张比例渲染**
- **双栏布局**：左栏（教育/实习/项目等主体内容）+ 右栏（技能/证书/语言等辅助信息）
- **技能进度条**展示
- **头部区域**：姓名 + 职位 + 联系方式（电话/邮箱/城市，带边框包裹）
- **反向锚定**：红色虚线框标注"教育经历"（hover 高亮，点击定位到左侧表单）

### 渲染引擎核心设计
1. **数据流**：`resumeData.sections` → 根据 `templateMeta.layout` 排列 → 渲染对应 Section 组件
2. **模板切换**：修改 CSS 变量（theme.primary/theme.text/theme.background）+ layout 配置
3. **反向锚定**：每个 Section 组件通过 `ResumeSectionWrapper` 包裹，暴露 `sectionId` ref，点击预览区模块时 scrollIntoView 到左侧表单

### Section 组件清单（14 个）
| Section ID | 组件名 | 说明 | 渲染特点 |
|---|---|---|---|
| profiles | ResumeProfiles | 社交主页 | 链接列表 |
| summary | ResumeSummary | 个人总结 | 富文本 HTML |
| education | ResumeEducation | 教育经历 | 时间线 + 学校/专业/GPA |
| experience | ResumeExperience | 实习/工作经历 | 时间线 + 公司/职位/描述 |
| projects | ResumeProjects | 项目经历 | 时间线 + 项目名/描述 |
| volunteer | ResumeVolunteer | 社团组织经历 | 时间线 + 组织/职位/描述 |
| languages | ResumeLanguages | 语言能力 | 标签或进度条 |
| skills | ResumeSkills | 技能 | 名称 + 进度条 + 关键词 |
| interests | ResumeInterests | 兴趣爱好 | 关键词标签 |
| certifications | ResumeCertifications | 证书 | 时间 + 名称/颁发机构 |
| awards | ResumeAwards | 荣誉奖项 | 时间 + 名称/描述 |
| publications | ResumePublications | 出版物 | 时间 + 名称/描述 |
| references | ResumeReferences | 推荐信 | 姓名/职位/联系方式 |
| custom | ResumeCustom | 自定义 | 通用渲染 |

### 4.2 Signatures

```jsx
// ResumePreview.jsx — A4 预览容器
const ResumePreview = ({ resumeData, templateMeta, onSectionClick })
// resumeData: { basics, metadata, sections } — 简历完整数据
// templateMeta: { layout, theme, typography, css, page } — 模板配置
// onSectionClick: (sectionId: string) => void — 反向锚定回调

// ResumeHeader.jsx — 简历头部
const ResumeHeader = ({ basics })
// basics: { name, headline, email, phone, location, url, picture }

// ResumeSkills.jsx — 技能（含进度条）
const ResumeSkills = ({ items })
// items: [{ id, name, level, keywords, visible }]

// ResumeEducation.jsx — 教育经历
const ResumeEducation = ({ items })
// items: [{ id, institution, area, studyType, date, score, summary, visible }]

// ResumeExperience.jsx — 实习/工作经历
const ResumeExperience = ({ items })
// items: [{ id, company, position, date, location, summary, visible }]

// ResumeProjects.jsx — 项目经历
const ResumeProjects = ({ items })
// items: [{ id, name, date, description, summary, keywords, url, visible }]

// ResumeSectionWrapper.jsx — 通用 section 包装
const ResumeSectionWrapper = ({ sectionId, name, visible, onAnchorClick, children })
// sectionId: string — 用于反向锚定定位
// onAnchorClick: (sectionId) => void — 点击时通知父组件
// visible: boolean — 控制该 section 是否显示
```

### 4.4 验收标准
1. A4 预览容器尺寸正确（210mm × 297mm），可缩放显示
2. 使用 PRD 示例 JSON 数据渲染出完整简历
3. 双栏布局正确：左栏（教育/实习/项目）+ 右栏（技能/证书等）
4. 技能进度条正确渲染
5. Section 组件 hover 显示蓝色高亮边框
6. 模板 CSS 变量切换可改变主题色/字体
7. `visible: false` 的 section 不渲染
