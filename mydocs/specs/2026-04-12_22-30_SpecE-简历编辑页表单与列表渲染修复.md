# Spec E: 简历编辑页表单与列表渲染修复

## Open Questions
- [x] Q: 左侧表单需要包含哪些 Section？  
  **A:** 基本信息（头像/姓名/电话/邮箱/城市/求职意向）、个人总结、教育经历、实习经历、项目经历（本期 MVP 范围，后续可扩展）

## Requirements

### In-Scope
1. **修复简历列表页渲染问题**
   - 列表页调用 `resumeApi.listByUserId` 成功返回数据后，正确渲染简历卡片
   - 每张卡片显示标题、最后更新时间（相对时间）
   - 鼠标悬停显示「手动编辑」「AI 编辑」两个操作按钮

2. **修复新建简历跳转时 `undefined` 问题**
   - `TemplateSelector` 组件创建简历成功后，后端返回的 `resume.id` 正确传递给 `navigate('/resume/edit/${resumeId}')`
   - 路由参数 `:id` 能正确解析为数字 ID

3. **实现左侧编辑表单（完整版）**
   - 左侧 480px 宽编辑区实现完整表单结构
   - 顶部 Tab 导航：编辑 / 模板 / AI / 样式（本期实现编辑 Tab，其余 Tab 显示占位）
   - **基本信息 Section**：
     - 头像占位 + 添加头像按钮（占位，后续实现上传）
     - 快速添加常用字段按钮：当前状态 / 性别 / 籍贯 / 主页链接 / GitHub / 自定义
     - 姓名 / 电话 / 邮箱 / 城市（2×2 网格布局）
     - 求职意向 headline（单列）
   - **个人总结 Section**：
     - 工具栏：撤销 / 重做 / 加粗 / 斜体 / 无序列表 / 有序列表 / 左对齐 / 居中 / 右对齐 / 链接
     - 文本域（高度自适应，最小 120px）
   - **教育经历 Section**：
     - 工具栏（同上）
     - 学校名称 / 专业 / 学历 / 起止时间（单列排列）
     - 支持多条：右上角「+」按钮新增，每条右侧「×」按钮删除
     - 默认初始化 1 条空数据
   - **实习经历 Section**：
     - 工具栏（同上）
     - 公司 / 职位 / 起止时间 / 工作内容（textarea）
     - 支持多条增删
   - **项目经历 Section**：
     - 工具栏（同上）
     - 项目名称 / 起止时间 / 项目描述（textarea）
     - 支持多条增删
   - **技能 Section**：
     - 技能名称 / 熟练度（1-5 滑块）/ 关键词（tags 输入，回车添加）
     - 支持多条增删
   - **证书 Section**：
     - 证书名称 / 颁发机构 / 获取日期
     - 支持多条增删
   - 表单数据与 `resumeData` 双向绑定，修改后自动更新右侧预览

4. **右侧预览保持只读**
   - 右侧 `ResumePreview` 组件已实现，本期无需改动
   - 保持点击 Section 的 `onSectionClick` 回调（后续实现反向锚定）

5. **数据持久化**
   - 表单修改后自动调用 `resumeApi.update` 保存到后端
   - 实现防抖保存（500ms 延迟，避免频繁请求）
   - 保存状态提示：保存中 / 已保存 / 保存失败

### Out-of-Scope
- 头像上传功能（后端未实现）
- Section 拖拽排序（PRD 未明确要求，后续按需添加）
- 反向锚定（点击右侧 Section 左侧自动滚动到对应表单，需实现 IntersectionObserver）
- AI 编辑模式（需要 AGUI 协议对接，Spec 独立）
- 模板 / 样式 Tab 内容（本期仅实现编辑 Tab）

## Dependencies
- **前置依赖**: Spec A（全局布局）、Spec B（数据层与列表页）、Spec C（简历模板）、Spec D（渲染引擎）
- **可并行**: 无（本期单线实施）

## Design Decisions
1. **完整功能范围**：不做 MVP 裁剪，一次性实现所有 Section 表单（基本信息、总结、教育、经历、项目、技能、证书）
2. **可复用组件设计**：`SectionFormItem` 作为通用容器，支持标题、工具栏、增删按钮，所有 Section 复用
3. **防抖保存策略**：500ms 延迟调用 `resumeApi.update`，避免每次输入都触发请求
4. **多条目数据结构**：`resumeData.sections.education` 等字段为数组，遍历时为每个元素生成唯一 key（使用 `id` 字段或索引）
5. **表单双向绑定**：使用受控组件模式，所有输入框 value 绑定到 `resumeData`，onChange 合并更新
6. **工具栏占位**：本期工具栏按钮点击仅打印日志，后续对接富文本编辑器（如 TipTap 或 Slate）
