## 2. Research Findings

### 设计稿分析（image-5.png 模板选择弹窗）
- **弹窗式布局**，顶部关闭按钮（×）
- **标题**："推荐简历模板"
- **网格布局**展示模板卡片（3~4 列）：
  - 第一个为 "新建空白简历"（大号 + 图标）
  - 其余为预置模板卡片，每个含缩略图预览
- **模板列表（5+套）**：
  1. 人事简历模板
  2. 社招通用模板
  3. 财务简历模板
  4. 产品经理模板
  5. 销售简历模板
  6. 程序员简历模板
  7. 校招通用模板
  8. 实习通用模板
  9. 新媒体运营模板
- 统一设计风格：浅蓝/灰白配色

- 模板数据为平台预设，初始化时通过 SQL INSERT 预置
- `meta` 字段以 TEXT/JSON 存储完整模板配置
- 模板预览图暂时使用占位图（后续替换为实际图片 URL）

### 4.2 Signatures

```java
// ResumeTemplate.java
@Data @TableName("resume_template")
public class ResumeTemplate implements Serializable {
    @TableId(type = IdType.AUTO)
    private Long id;
    private String name;           // 模板标识名（rhyhorn, glalie 等）
    private String title;          // 模板显示名（经典、简约 等）
    private String preview;        // 预览图 URL
    private String permission;     // JSON: ["free"] / ["vip"]
    private String meta;           // JSON: 模板配置(layout/theme/typography/css/page)
    private Integer columns;       // 栏数
    private Boolean isVip;         // 是否 VIP 模板
    private String description;    // 模板描述
    private Date createdAt;
    private Date updatedAt;
}

// ResumeTemplateMapper.java
@Mapper
public interface ResumeTemplateMapper extends BaseMapper<ResumeTemplate> {}

// ResumeTemplateService.java
@Service
public class ResumeTemplateService extends ServiceImpl<ResumeTemplateMapper, ResumeTemplate> {
    public List<ResumeTemplate> listAll();
    public ResumeTemplate getById(Long id);
}

// ResumeTemplateController.java
@RestController @RequestMapping("/api/resume-template")
public class ResumeTemplateController {
    @GetMapping("/list")           List<ResumeTemplate> list();
    @GetMapping("/{id}")           ResumeTemplate getById(@PathVariable Long id);
}
```
