### 事实与约束
1. **现有项目结构清晰**：前端 React SPA + 后端 Spring Boot 多模块
2. **数据库双引擎**：SQLite(testing) + MySQL(pre/product)，建表 SQL 需同时提供
3. **简历数据结构复杂**：PRD JSON Schema 包含 14 个 section 类型
4. **JSON 存储策略**：简历的 `data` 字段以 JSON 存储在数据库中
5. **前端渲染方案已确认**：HTML+CSS 渲染，A4 预览 + 实时数据绑定
6. **已有 AGUI 体系**：3 个 Agent 可复用于 AI 编辑
7. **品牌名称冲突**：设计稿使用 "UP" 品牌，现有代码使用 "智聘鼠"，需确认以哪个为准
8. **设计稿含侧边栏导航**：现有前端无侧边栏，需新增全局导航组件
9. **AI 编辑功能已确认**：入口按钮 + 对话弹窗（复用 AGUI Agent）

### 风险与不确定项
1. **简历渲染复杂度高**：A4 纸张预览 + 双栏布局 + 技能进度条 + 实时渲染 + 模板切换，是前端最复杂的部分
2. **品牌名称待确认**：设计稿 "UP" vs 现有 "智聘鼠"
3. **模板 CSS 系统**：模板的 CSS/布局/主题配置需映射到 React 组件渲染
4. **富文本编辑**：个人总结等字段使用富文本，需要编辑器组件（如 TipTap/Quill）
5. **性能风险**：JSON 数据量大 + 实时预览可能卡顿
6. **反向锚定**：右侧模块点击定位到左侧表单，需要精确的 DOM 位置计算

## 3. Innovate (Options & Decision)

### 核心决策一：简历渲染引擎

#### Option A：自研 React 组件渲染（推荐）
- **方案**：每个 section 类型对应一个 React 组件（ResumeHeader, ResumeSkills, ResumeEducation 等），通过模板的 layout 配置决定组件排列，通过 theme/typography CSS 变量控制样式
- **Pros**：
  - 完全可控，可精确还原设计稿
  - 与 React 生态无缝集成，状态管理自然
  - 实时预览天然支持（数据驱动渲染）
  - 反向锚定容易实现（组件 ref + scrollIntoView）
  - 模板切换只需换 CSS 变量和 layout 配置
- **Cons**：
  - 开发量较大（需实现 14 个 section 组件）
  - 需自行处理 A4 分页、打印样式

#### Option B：基于 reactive-resume 开源项目二次开发
- **方案**：fork reactive-resume 的渲染引擎，适配到项目
- **Pros**：
  - 已有完整渲染实现，A4 分页/打印/模板都支持
  - PRD 中的数据结构与 reactive-resume 高度相似
- **Cons**：
  - 引入大量非项目依赖
  - 技术栈差异（reactive-resume 用 TypeScript + Tailwind + Zustand）
  - 二次开发维护成本高
  - 与现有纯 CSS 风格不一致

#### Option C：iframe + 后端渲染 HTML
- **方案**：后端根据模板生成 HTML，前端用 iframe 加载
- **Pros**：前端开发量最小
- **Cons**：实时预览体验差，反向锚定难以实现，不满足 PRD 需求

### Decision: Option A（自研 React 组件渲染）
- **Why**：最符合项目需求（实时预览 + 反向锚定 + 模板切换），与现有技术栈一致，长期可维护
- **核心设计**：
  - 数据层：简历 JSON 数据 → React state
  - 渲染层：Section 组件库 + 模板 CSS 变量 + Layout 配置
  - 交互层：表单 onChange → 数据更新 → 预览重渲染

### 核心决策二：前端新增依赖

#### 需要引入的库
1. **富文本编辑器**：推荐 `@tiptap/react` + `@tiptap/starter-kit`
   - 轻量、可扩展、React 生态首选
   - 用于个人总结、项目描述等富文本字段
2. **图标库**：推荐 `lucide-react`
   - 轻量 SVG 图标库，替代设计稿中的各图标
3. **UI 组件基础**：不引入完整 UI 库，保持纯 CSS + 自研组件
4. **A4 预览**：自研 A4 容器组件，CSS `@page` + `mm` 单位

#### 不引入的库
- 不引入 Tailwind CSS（保持现有纯 CSS 风格）
- 不引入 Zustand/Redux（保持现有 React state + props 模式，简单够用）
- 不引入完整简历渲染库

### 核心决策三：后端数据存储

- **resume 表**：核心字段 + `data` JSON 字段（存储完整的简历结构数据）
- **resume_template 表**：核心字段 + `meta` JSON 字段（存储模板配置：layout/theme/typography/css）
- **不拆分 sections 为独立表**：JSON 存储简化查询，前端按需解析

    private Long sourceResumeId;   // 来源简历 ID

    private Long templateId;       // 关联模板 ID
