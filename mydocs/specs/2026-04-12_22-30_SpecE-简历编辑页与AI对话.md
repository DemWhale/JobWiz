## 1. Requirements (Context)
- **Goal**: 实现简历编辑页（1:1 还原设计稿 image-4.png + image-6.png），包含左右分栏（表单 + 实时预览 + 反向锚定）和 AI 编辑对话弹窗
- **In-Scope**:
  1. 简历编辑页左右分栏布局
  2. 左侧编辑面板：基本信息表单 + 各 Section 表单 + 快速添加字段 + 富文本编辑器
  3. 左侧底部 tab：编辑 | 模板 | AI | 样式
  4. 顶部工具栏：返回 + 标题 + 保存状态 + 模块顺序/字号/行高/边距/主题色 + 导出
  5. 右侧实时预览（使用 Spec D 的渲染引擎）
  6. 反向锚定：右侧预览区 section 可点击定位到左侧表单
  7. AI 编辑对话弹窗（复用 AGUI Agent）
  8. 自动保存机制
- **Out-of-Scope**:
  1. PDF 导出功能
  2. 一键翻译/按职位改写
  3. 深色模式

### 设计稿分析（image-6.png 反向锚定）
- 右侧预览区各模块可 hover 高亮
- 点击右侧模块，左侧表单自动滚动到对应 section

### AI 编辑对话弹窗设计
- 从编辑页左侧 tab "AI" 或简历列表的 "✨ AI 编辑" 按钮触发
- 弹窗式对话界面，复用现有 AGUI Agent
- 支持与 Agent 对话修改简历字段
- Agent 返回 JSON 格式修改建议，用户确认后应用

### 自动保存机制
- 表单数据变更后 debounce 2 秒自动保存
- 顶部显示"已保存 X 分钟前"
- 保存调用 `PUT /api/resume/update`

### 4.2 Signatures

```jsx
// ResumeEditor.jsx — 编辑页主组件
const ResumeEditor = ({ userId, resumeId, templateId })
// 从 URL params 获取 resumeId 或 templateId
// 管理简历数据状态，自动保存，反向锚定

// ResumeForm.jsx — 左侧编辑面板
const ResumeForm = ({ resumeData, onChange, activeTab, onSectionRef })
// resumeData: 完整简历数据
// onChange: (path, value) => void — 表单字段变更回调
// activeTab: 'edit' | 'template' | 'ai' | 'style'
// onSectionRef: (sectionId, ref) => void — 注册 section ref 用于反向锚定

// EditorToolbar.jsx — 顶部工具栏
const EditorToolbar = ({ resumeTitle, saveStatus, templateMeta, onMetaChange, onBack })
// saveStatus: 'saving' | 'saved' | 'unsaved'
// templateMeta: 模板配置
// onMetaChange: (key, value) => void

// AiChatModal.jsx — AI 对话弹窗
const AiChatModal = ({ open, onClose, agentId, resumeData, onApplyChanges })
// open: boolean
// onClose: () => void
// agentId: 'baseinfo' | 'interest' | 'edubackground'
// resumeData: 当前简历数据（传给 Agent 作为上下文）
// onApplyChanges: (changes: object) => void — 应用 Agent 返回的修改
```
