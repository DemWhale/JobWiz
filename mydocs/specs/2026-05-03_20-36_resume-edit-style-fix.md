# Spec: 简历编辑页样式修复

## 当前理解

本轮目标是修复普通简历编辑模式下的页面样式问题，保证左侧编辑区和右侧预览区布局稳定、可滚动、可阅读，并让两侧表现为两个独立工作模块，不改动业务逻辑和数据流。

## 范围

In-Scope:
- 补齐 `ResumeEdit` 普通模式的基础布局样式。
- 约束左侧表单区宽度与滚动。
- 约束右侧预览区背景、居中和滚动表现。
- 将左右区块改造成两个独立模块面板，而不是直接占满左右半屏。
- 适度修正 A4 预览容器在编辑页中的缩放/最大宽度表现。
- 为右侧预览增加默认适应容器展示与百分比缩放控制。
- 修复基础信息编辑与右侧头部预览的联动关系。

Out-of-Scope:
- AI 模式布局重做。
- 表单字段结构调整。
- 预览组件渲染逻辑调整。
- 富文本工具栏能力接入。

## 涉及文件

- `frontend/jobwiz-console/src/pages/ResumeEdit.css`
- 必要时小范围调整 `frontend/jobwiz-console/src/components/resume/ResumePreview.css`
- 如需细修，再补 `ResumeForm.css`

## Done Contract

完成标准:
- 普通编辑模式下页面为稳定的左右分栏。
- 左侧表单区独立滚动，右侧预览区独立滚动。
- 右侧 A4 预览在常见桌面宽度下不会贴边或明显溢出。
- 不引入新的交互行为，不修改现有保存与编辑逻辑。

## 计划

1. 为 `resume-edit-body`、普通模式 `resume-edit-left/right` 补齐 flex 布局。
2. 给左侧表单区设置固定宽度范围和边界线。
3. 调整右侧预览容器的内边距、居中和最小宽度策略。
4. 如有必要，微调 A4 容器在编辑页中的显示约束。

## 风险

- 现有 CSS 同时服务普通模式和 AI 模式，修改时需要避免互相覆盖。
- 不能通过大改 JSX 结构来掩盖样式问题，应优先修 CSS。

- 已修改 `ResumeEdit.css`：补齐普通模式 `resume-edit-body` 双栏布局、左栏宽度约束、右栏滚动区和 header 文本溢出控制。
- 已修改 `ResumeEdit.css`：增加桌面与移动断点，避免标题栏和左右栏在窄宽度下错位。

- 已修改 `ResumePreview.jsx`：增加预览缩放状态、默认适应容器缩放逻辑和百分比缩放控制。

- 已修改 `resume.css` 与 `ResumeForm.css`：补充头部链接文本和紧凑型简介输入的样式。
