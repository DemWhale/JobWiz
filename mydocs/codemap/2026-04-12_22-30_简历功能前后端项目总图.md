## Frontend (jobwiz-console)

### 架构层
- **入口**: `src/main.jsx` → `src/App.jsx`
- **路由**: React Router v7 (`/login`, `/profile`, `/`)
- **页面**: `src/pages/Login.jsx`, `src/pages/Profile.jsx`
- **组件**: `src/components/ChatWindow.jsx`, `QuickActions.jsx`, `InputArea.jsx`, `UserAvatar.jsx`
- **API**: `src/services/api.js` (axios, baseURL: `http://localhost:8080/api`)
- **样式**: CSS 文件与 JSX 一一对应，全局变量在 `index.css`

### 关键模块
- **Login**: 用户 ID 登录（默认 1001），无密码验证
- **HomePage**: 登录后主页，含 ChatWindow + QuickActions + InputArea
- **Profile**: 用户信息编辑表单（10 个字段）
- **UserAvatar**: 头像 + 信息面板浮层
- **ChatWindow**: 欢迎语 + QuickActions
- **QuickActions**: 5 个快捷会话项
- **InputArea**: 功能按钮 + 文本输入 + 发送按钮

### 技术栈
- React 19 + Vite 8
- react-router-dom 7
- axios
- 纯 CSS（无 CSS-in-JS / Tailwind）

### 外部依赖
- 后端 API: `http://localhost:8080/api/user-feature/*`

## Backend (job-wiz)

### 架构层（Maven 多模块）

```
job-wiz (parent pom)
├── job-wiz-common    # 公共：Agent、枚举、工具类
├── job-wiz-dal       # 数据访问层：Entity、Mapper、DB Config
├── job-wiz-service   # 业务逻辑层：Service、Config
└── job-wiz-start     # 启动层：Controller、Application、YAML
```

### 核心模块
- **Entity**: `UserFeature`（user_feature 表，14 个业务字段 + id/timestamp）
- **Mapper**: `UserFeatureMapper`（MyBatis Plus）
- **Service**: `UserFeatureService`（继承 ServiceImpl，CRUD + 条件查询）
- **Controller**: `UserFeatureController`（REST API，`/api/user-feature/*`）
- **Agent**: `BaseInfoAgent`, `InterestAgent`, `EduBackgroundAgent`（ReActAgent，AGUI 协议注册）
- **Config**: `AguiConfig`（AGUI 注册），`DashScopeModelConfig`（模型 Bean），`CorsConfig`，`JobWizMybatisPlusConfig`，`JobWizSqliteConfig`

### 数据库
- **SQLite**（testing profile）: `database/job_wiz.db`
- **MySQL**（pre/product profile）
- 当前仅 `user_feature` 一张表

### AGUI 端点
- `POST /agui/run/baseinfo` — 基础信息修改 Agent
- `POST /agui/run/interest` — 求职意向修改 Agent
- `POST /agui/run/edubackground` — 教育背景修改 Agent

### 技术栈
- Java 21 + Spring Boot 4.0.4
- MyBatis Plus 3.5.5
- AgentScope 1.0.11（AGUI 协议）
- DashScope (qwen3.5-flash)

## 跨项目流程（当前）

```
Frontend (Login) → POST /api/user-feature/user?userId=xxx → Backend (UserFeatureService)
Frontend (Profile) → POST /api/user-feature/save-or-update → Backend (UserFeatureService)
Frontend (HomePage) → 暂无真实 AI 对话，QuickActions/ChatWindow 仅为 UI
```
