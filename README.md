# JobWiz
AI智能招聘求职助手


企业级AI Agent 开发实战课程大纲

面向大学生与研究生，以 Java + Spring AI 为核心技术栈，围绕大模型、RAG、Rerank、Skills、ReAct Agent、AGUI 构建实战体系，全程采用 Vibe Coding 快速开发范式，完成陪伴式 AI 求职助手落地。

1 项目准备与前置知识

• 企业级 SaaS 开发环境搭建，Java 工程化项目初始化

• 前置技术扫盲：大模型基础、RAG、记忆机制、Skills 工具体系、AGUI

• LangGraph 与 ReAct Agent 原理与基础实践

• 传统开发：用户信息、画像、引导流程的 CRUD 与前端编码

• Vibe Coding 与 SDD 规范落地，快速迭代开发思想

2 核心业务模块（实战主体）

• 用户画像生成：大模型推理、Prompt 工程、结构化调用与持久化存储

• 日常闲聊交互：用户画像与记忆联动、AGUI 实际应用

• 意图识别：基于 LangGraph 实现意图分类与子 Agent 承接

• 简历修改生成：用户画像 + 经历 + 搜索词改写 + 多路召回 + RAG 匹配相似简历

• 简历投递：Skills 能力实现岗位筛选决策，对接外部投递接口

• 能力提升：面经物料清洗与分类，RAG + Rerank 实现个性化题目推荐与能力评估

• 模拟面试：RAG + Rerank 支撑题库，结合用户画像做系统 Prompt 与多轮交互刻画

• 全流程 Agent 编排与状态流转

3 Agent 评测、产品部署与维护

• 项目上线部署：流式输出、AGUI 部署、Node 服务对接

• Agent 多维度评测：问题采样、知识库校验、命中率、幻觉率等指标评估

• 版本迭代与 Git 协作管理

• 基于线上数据持续优化 Agent 逻辑、Prompt 与检索策略

技术栈亮点

Java / Spring AI / 大模型 / RAG / Rerank / Skills / ReAct Agent / LangGraph / AGUI / Vibe Coding

项目亮点
全备的端到端前后端一体vibe coding，深度使用agent关键技术与详细的技术设计，具备逆向评测迭代agent的亮点过程
